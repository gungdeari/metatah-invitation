# Bali Metatah Digital Invitation

Static React + Vite + TypeScript + Tailwind CSS digital invitation.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The generated `dist/` folder can be deployed directly to Netlify as a static site.
Guest personalization remains available through `?kepada=Nama` (and the existing `?to=Nama` fallback).
